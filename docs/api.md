- `POST /api/v1/versions/{version_id}/evaluations`
- `POST /api/v1/approvals/versions/{version_id}`
- `POST /api/v1/approvals/{approval_id}/approve`
- `POST /api/v1/deployments/versions/{version_id}`
- `POST /api/v1/deployments/{deployment_id}/rollback`
- `POST /api/v1/drift/versions/{version_id}`
- `GET /api/v1/audit`
- `GET /metrics`
